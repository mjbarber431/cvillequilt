Back to Basics with BIG Stitch Quilting – Kirsten Niemann

Kirsten Niemann describes Big Stitch quilting as using a thick, decorative thread or yarn to hand-quilt a quilt sandwich using a running stitch.  But that definition doesn’t fully encompass the beauty and intricacies in design and embellishment that simple running stitches bring to an understated (or overstated) pieced background.  Join us and learn how to create beautiful, hand-quilted projects using BIG stitch quilting.  There is no cost for this mini-workshop.  Limited to 20 participants (possibly a few more, depending on interest).

Things to bring:

  • Small scissors

  • Thimble, if you use one

  • Needle threader

  • Reading/magnifying glasses, if you use them
